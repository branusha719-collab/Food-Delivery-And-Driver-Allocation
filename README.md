# Food Delivery & Driver Allocation System

A MERN-stack food delivery and intelligent driver allocation platform built collaboratively across six specialized roles.

For full backend setup, API contracts, state machine details, and integration guides for each role, see the [Backend Documentation](file:///Users/anushabr/Documents/Food-Delivery-And-Driver-Allocation/backend/README.md).
